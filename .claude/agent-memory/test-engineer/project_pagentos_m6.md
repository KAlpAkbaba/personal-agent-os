**How to apply:** (1) **`state/BUILD_STATE.json` is NOT auto-updated by `quality-gate.ps1`** — after this M6 verification it still read `current_milestone: M6, status: NOT_STARTED, last_completed_milestone: M5`, with `quality_gate.scope` describing stale M5-era numbers, even though M6 was fully merged (commits `6c71ef0`/`a2158ac`/`77ebf4a`), ADR-0024 was recorded, and `docs/ROADMAP.md` already says M6 "Delivered". This directly violates CLAUDE.md's Definition of Done ("a milestone is not done until ... state/BUILD_STATE.json is updated") even when every technical gate is green — always check this file's actual JSON content, don't infer milestone-closed status from git log or docs alone. (2) One non-blocking coverage gap: `app/selfhealing/monitoring.py`'s `_MAX_EVIDENCE_BYTES` (64KB) rejection and the `_optional_str` per-field length-limit rejections in `draft_from_supervisor_report` are implemented but never exercised by `test_supervisor_report_validation` or any other test (same pattern as the M3 coverage-gap finding — implementation is correct, just untested).
