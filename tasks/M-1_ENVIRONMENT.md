# M-1 Environment Task

## Objective

Create a reproducible local development foundation without requiring a GPU.

## Required outputs

- `docs/LOCAL_ENV_REPORT.md`
- actual toolchain/version decision
- repository initialization/hygiene
- a single `scripts/preflight` command
- a single `scripts/quality-gate` command placeholder that can grow with the project
- one consolidated owner action list if UAC/reboot/login is unavoidable

## Do not

- provision production cloud yet;
- install local foundation LLMs;
- buy/recommend GPU before inventory;
- modify unrelated owner files/settings.
